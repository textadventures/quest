import { Card, CardGrid, LinkCard } from '@astrojs/starlight/components';

<CardGrid>
	<Card title="Get started quickly" icon="rocket">
		You don't need to know how to program to use Quest Viva. But you might pick up some handy programming knowledge along the way.

		Everything about your game is displayed in plain English, in a point-and-click editor. There's no syntax to remember and nothing to install.

		A full [tutorial](/tutorial/tutorial-introduction) is included, and help is always available on [Discord](https://textadventures.co.uk/community/discord) and [GitHub Discussions](https://github.com/textadventures/quest/discussions).
	</Card>
	<Card title="Text adventures and gamebooks" icon="puzzle">
		Write a classic **text adventure**, where players explore rooms, pick up objects, solve puzzles and talk to characters by typing commands or clicking links.

		Or write a **gamebook** - a branching story where the reader picks what happens next from a set of choices at the end of each passage.

		Browse published [text adventures](https://textadventures.co.uk/games/platform/quest) and [gamebooks](https://textadventures.co.uk/games/platform/quest-gamebook), or [see what Quest Viva can do](/intro).
	</Card>
	<Card title="Surprisingly powerful" icon="star">
		Quest Viva is designed to be easy to learn, but it has huge power when you need it.

		There's a fully featured [scripting language](/scripts) behind the scenes, which you can dip in and out of as required. Use variables and functions, share behaviour between objects using object types, and package up advanced functionality into libraries to reuse and share.
	</Card>
	<Card title="Graphics, sound and video" icon="youtube">
		Who says text adventures are all about text?

		You can add [pictures](/howto/multimedia/images) to your game, along with [music and sound effects](/howto/multimedia/adding-sounds), and you can even embed [video](/howto/multimedia/adding-videos) from YouTube.

		And you can go further still, [customising the user interface](/howto/ux/customising-the-ui) with your own HTML, CSS and JavaScript, to get your game looking exactly how you want.
	</Card>
	<Card title="Create in your browser, or on your desktop" icon="laptop">
		Quest Viva runs in any modern web browser - there's nothing to install, and it works on Windows, Mac, Linux and Chromebooks.

		Prefer to work offline? [Download the desktop app](/download) for Windows, Mac or Linux. It's the same editor either way, and the same game files, so you can switch between them whenever you like.
	</Card>
	<Card title="Plays on any device" icon="mobile-android">
		Your finished game runs directly in the player's web browser, on phones, tablets and computers alike, using a responsive layout that adapts to any screen size.

		There's nothing for players to download or install, and nothing to sign up for - they just follow a link and start playing.
	</Card>
	<Card title="Saves without logging in" icon="cloud-download">
		Players don't need an account anywhere to save their progress. Games save to the browser's own storage, with multiple save slots, and players can also save a game to a file to keep or move elsewhere.

		Once a game has loaded, everything runs in the browser - so it keeps working even if the network drops.
	</Card>
	<Card title="Share with the world" icon="open-book">
		[Publish your game](/publishing/publishing) to [textadventures.co.uk](https://textadventures.co.uk/), the top destination for people looking for text adventure games to play.

		Or [host it yourself](/publishing/hosting) - on your own website, or as a single HTML file you can upload anywhere. It's your game, and you choose where it lives.
	</Card>
	<Card title="Any language" icon="translate">
		Create games in English, French, German, Spanish, Dutch, Italian, Portuguese, Danish, Norwegian, Icelandic, Greek, Russian, Romanian - even Esperanto.

		Or [create your own translation](/advanced-topics/translation).
	</Card>
	<Card title="It's free - and so are you" icon="heart">
		Quest Viva is free and [open source](/developers/open-source), licensed under the [MIT License](https://opensource.org/license/MIT).

		You can sell the games you make with it. You can [modify the source code](https://github.com/textadventures/quest) and use it inside closed source commercial applications.

		You don't need to ask for permission - you already have it.
	</Card>
</CardGrid>
