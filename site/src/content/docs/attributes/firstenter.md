---
title: firstenter
---

"firstenter" is a [script](/types/script) attribute. It is run the first time that a player enters an object (room), *after* the room description is printed.

Quest keeps track of whether a room has been visited before by checking the value of the [visited](/attributes/visited) attribute.

See also [beforefirstenter](/attributes/beforefirstenter), [enter](/attributes/enter), [visited](/attributes/visited).
