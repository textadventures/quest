---
title: container_base
---

The "container\_base" type is defined in CoreTypes.aslx. It implements base functionality for the container types, so you shouldn't need to inherit this directly - you should use [container\_open](/attributes/container_open), [container\_closed](/attributes/container_closed), [container\_limited](/attributes/container_limited) or [surface](/attributes/surface) instead, unless you are defining your own container type.
