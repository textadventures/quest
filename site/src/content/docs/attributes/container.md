---
title: container
---

The "container" type is defined in CoreTypes.aslx. It implements an open container by straightforwardly inheriting the [container\_open](/attributes/container_open) type.

By inheriting the "container" type in an object, it becomes by default [openable](/attributes/open) and [closable](/attributes/close). "Open" and "Close" are added as [displayverbs](/attributes/displayverbs).
