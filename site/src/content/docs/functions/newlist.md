    NewList ()

**New in Quest 5.4**

Returns an empty [list](/types/list). The list can contain any type of data, or a mixture - for example, both objects and strings.

If the list will only contain one type of data (as will usually be the case), you should use [NewStringList](/functions/newstringlist) or [NewObjectList](/functions/newobjectlist) instead.

NOTE: This a [hard-coded function](/functions/hardcoded).
