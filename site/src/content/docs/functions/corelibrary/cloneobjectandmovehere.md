    CloneObjectAndMoveHere (object)
    
**New in Quest 5.7**    

Returns an [object](/types/object). Helper function for cloning objects. Clones the object using the [CloneObject](/functions/corelibrary/cloneobject) function and also moves it to current room.  For more details, see that function.
