---
title: SetDark
---

    SetDark(room)

Set a **room** to dark. Objects and Exits can't be seen unless there is a lightsource object in this room.

See also [SetLight](/functions/corelibrary/setlight), [SetObjectLightstrength](/functions/corelibrary/setobjectlightstrength),[SetExitLightstrength](/functions/corelibrary/setexitlightstrength), [CheckDarkness](/functions/corelibrary/checkdarkness)

This command was added in Quest 5.3.
