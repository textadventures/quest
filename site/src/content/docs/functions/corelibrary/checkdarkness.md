---
title: CheckDarkness
---

    CheckDarkness()

Returns a [boolean](/types/boolean) - **true** if the player is in an room, which is dark and has no strong lightsources in it.

See also [SetDark](/functions/corelibrary/setdark), [SetLight](/functions/corelibrary/setlight), [SetObjectLightstrength](/functions/corelibrary/setobjectlightstrength), [SetExitLightstrength](/functions/corelibrary/setexitlightstrength)

This command was added in Quest 5.3.
