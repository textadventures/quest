title: SetLight

    SetLight(room)

Set a **room** to light.

See also [SetDark](/functions/corelibrary/setdark), [SetObjectLightstrength](/functions/corelibrary/setobjectlightstrength), [SetExitLightstrength](/functions/corelibrary/setexitlightstrength), [CheckDarkness](/functions/corelibrary/checkdarkness)

This command was added in Quest 5.3.
